# Yash Kumar - Portfolio Website

Personal portfolio website showcasing my work as a Machine Learning Engineer.

## About

This is a modern, responsive portfolio website built with clean HTML5 and CSS3. The design is inspired by professional developer portfolios, featuring a minimalist aesthetic and clear content organization.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Clean Layout**: Professional header with navigation, main content area, and footer
- **Semantic HTML**: Uses proper HTML5 semantic elements for better accessibility
- **Fast Loading**: Minimal dependencies, mostly static HTML/CSS
- **Easy to Update**: Simple structure makes it easy to update content

## Structure

- `index.html` - Main HTML file with all content
- `style.css` - CSS stylesheet for styling and responsive design
- `assets/` - Directory containing images and CV

## Sections

1. **Header** - Navigation and site title
2. **About** - Introduction and professional summary
3. **Experience** - Work experience with detailed descriptions
4. **Projects** - Key projects with technical details
5. **Technical Skills** - Organized by category
6. **Publications** - Academic publications and papers
7. **Education** - Educational background
8. **Footer** - Contact information and social media links

## Local Development

To view the website locally:

```bash
# Option 1: Using Python
python3 -m http.server 8000

# Option 2: Using any static file server
# Then open http://localhost:8000 in your browser
```
